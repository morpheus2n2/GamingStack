# Getting Started

## What you need

- Windows 10 or 11, 64-bit.
- An internet connection (apps are downloaded as they install).
- **winget** (the "App Installer"). Windows 11 and recent Windows 10 already have it. If it is missing,
  GamingStack tells you and skips the winget apps instead of failing.

## Download and run

1. Get `GamingStackGUI.exe` from the [latest release](https://github.com/morpheus2n2/GamingStack/releases/latest).
2. Double-click it and say **Yes** to the administrator prompt. Admin is needed to install apps and to
   change the settings you approve.
3. If Windows SmartScreen warns you, that is because the app is new and not yet code-signed. Read
   [Security and Scans](Security-and-Scans) first if you like, then choose **More info > Run anyway**.

## Your first run

1. Watch the intro (or press **SPACE** to skip it).
2. Choose your setup type: **1** Gaming, **2** Office, **3** Developer.
3. Say yes to the whole list, or pick apps one at a time.
4. Choose your safety net (a restore point always happens; a full disk image is optional).
5. Go through the tweak screens - say no to anything you are not sure about.
6. On the **Final Check**, read the list, type `GO` and press Enter.
7. Watch it work. Press **C** any time to stop after the current item.
8. Read the summary. Your log, undo script and build sheet are listed there.

## Handy keys

| Key | What it does |
|---|---|
| SPACE | Skip the intro (or open the installer from the desktop) |
| Esc | Close the app (blocked while a backup or install runs) |
| C | Stop after the current item while installing |
| R | On the first screen: repeat your last setup |

## Settings

Start menu > Display Properties: boot colours, boot style, UI scale (100% is the default - try 125% or
150% on a 4K screen) and the screensaver delay.
