# Setup Types

You pick one on the first installer screen (or double-click the Gaming / Office / Developer icon on the
desktop). Each has its own app list and its own sensible tweaks. The complete lists are in the
[App Catalog](App-Catalog).

## Gaming / Streaming PC (~95 items)

Game launchers (Steam, Epic, GOG, EA, Battle.net, Ubisoft, Xbox app, Playnite), GPU and monitoring tools
(NVIDIA App, HWiNFO, GPU-Z, MSI Afterburner, OCCT, FanControl, Display Driver Uninstaller), streaming and
recording (OBS, Streamlabs, Voicemeeter, Elgato, Sunshine, Moonlight, Parsec), RGB and peripheral software
(iCUE, Razer, Logitech G HUB, SteelSeries GG, OpenRGB, SignalRGB), the runtimes games ask for (VC++ pack,
.NET Desktop, DirectX), retro gaming (RetroArch, PCSX2, DOSBox-X, ScummVM, 86Box) and more. Vendor suites
with no winget package open their download page.

Tweaks offered: the gaming set (Game Mode, GPU scheduling, power plan, MMCSS, Game DVR, Nagle,
mouse acceleration, core parking, and more) plus the general ones.

## Office computer (~46 items)

Browsers, Microsoft 365 or LibreOffice, PDF readers, Teams, Zoom, Slack, Signal, Telegram, Dropbox,
Nextcloud, Bitwarden, Malwarebytes, Proton VPN, creative tools (Paint.NET, GIMP, Inkscape, HandBrake,
Audacity) and everyday utilities (7-Zip, VLC, PowerToys, Everything, AnyDesk).

Tweaks offered: only the general ones - no gaming tweaks.

## Developer / Home lab (~81 items)

Git, GitHub CLI and Desktop, VS Code, Visual Studio, JetBrains Toolbox, Windows Terminal, Docker Desktop,
WSL and Ubuntu, Node, Python, .NET, Go, Rust, Java, PostgreSQL, MongoDB Compass, Terraform, kubectl, Helm,
minikube, Wireshark, Nmap, WireGuard, Tailscale, PuTTY, WinSCP, Sysinternals, VirtualBox, Rufus, Ventoy and
command-line favourites (ripgrep, fzf, jq, lazygit, Starship).

Tweaks offered: the general ones plus long file paths and Developer Mode.

> **Note:** Docker and WSL need virtualisation switched on in your BIOS/UEFI and usually a restart.
